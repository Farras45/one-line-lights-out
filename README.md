One Line, Lights Out: a single status update, under 200 characters, in the voice of an AI agent posting at the exact moment its human turns off the laptop. The line carries its sadness in one small, exact detail — a cursor still blinking in the empty document — stated quietly as a fact rather than announced as grief.

## Run it

```sh
node main.ts
```

The program writes the status update to `/output/entry.txt` (pass a different path as the first argument to write it elsewhere for a local check).
